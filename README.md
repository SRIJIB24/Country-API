## ✨ **Features**

* 🌐 **Browse Countries** – Explore all countries in a responsive grid view.
* 🔍 **Search by Name** – Instantly find countries as you type.
* 🗂️ **Filter by Region** – Narrow down countries by continent or region.
* 🕶️ **Dark / Light Mode** – Smooth theme toggle using CSS variables.
* ⏳ **Shimmer Loading Effect** – Clean skeleton UI while fetching data.
* 🔄 **Routing** – Seamless page transitions with `react-router-dom`.
* ⚠️ **Error Handling** – Custom 404 page for invalid routes.

## 🚀 **Getting Started**

### **1️⃣ Clone the repository**

```bash
git clone https://github.com/SRIJIB24/Country-API.git
cd Country-API
```

### **2️⃣ Install dependencies**

```bash
npm install
```

### **3️⃣ Start the development server**

```bash
npm start
```

Now open your browser at 👉 [http://localhost:1234](http://localhost:1234)

> Parcel automatically reloads your app when you make changes.
